# Logging

## Logger

- `Sandstorm\FilamentKeycloakAdmin\Logging\KeycloakAdminLogger` — container binding key for a host-provided
  PSR-3 logger instance. Not bound by the package itself. Resolved via
  `KeycloakAdminLoggerFactory::resolve($app)`, falling back to
  `Log::channel(config('filament-keycloak-admin.logging.channel'))` when unbound.

## Audit logging (write actions)

- `Sandstorm\FilamentKeycloakAdmin\Logging\LogsKeycloakAdminWrites` trait:
  - `logKeycloakWrite(array $context)` — info, "Keycloak admin write succeeded".
  - `logKeycloakWriteDenied(array $context)` — warning, "Keycloak admin write denied".
  - Adds `admin_id` (`Filament::auth()->id()`) automatically. Callers supply
    `self::LOG_CONTEXT_ACTION` plus any other non-PII context (ids, flags, counts — never bodies, names,
    emails, attribute values).
- `InteractsWithKeycloakWrites::runKeycloakWrite(string $action, array $context, callable $write): bool`
  uses both methods (identity writes: enable/disable, edit identity) and is also where a 401/403 denial is
  caught and turned into a UI notice instead of propagating.
- Five other write actions log directly via the trait (no denial handling — failures propagate as before):
  group add/remove, send password-reset email, remove credential, logout-all-sessions.

## HTTP tracing

- `Sandstorm\FilamentKeycloakAdmin\Http\KeycloakAdminHttpHandlerStackCustomizer` — interface with one
  method, `customizeHandlerStack(HandlerStack): HandlerStack`. Host app binds an implementation
  (`$this->app->bind(KeycloakAdminHttpHandlerStackCustomizer::class, MyCustomizer::class)`) to add its own
  middleware; `FilamentKeycloakAdminServiceProvider::buildHttpClient()` resolves it, if bound, and passes
  the client's handler stack through it before building the client. The package adds no middleware of its
  own — token requests carry the client secret, admin responses carry user PII.

## Config

- `filament-keycloak-admin.logging.channel` — fallback log channel, used only when no `KeycloakAdminLogger`
  is bound.
